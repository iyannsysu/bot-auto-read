## Обзор

**readsw** — это персональный WhatsApp self-bot, построенный на Node.js и библиотеке Baileys.
Он работает как ассистент единственного владельца и сосредоточен на трёх направлениях:
полной автоматизации статусов WhatsApp (историй), высококачественной загрузке медиа
и мульти-клон раннере, который позволяет нескольким дополнительным номерам работать
на одной кодовой базе.

Бот использует модульную плагинную систему — каждая функция является независимым
файлом плагина, который загружается автоматически при запуске. Текущая сборка включает
**69 плагинов и 156 команд**.

## Ключевые возможности

### Автоматизация статусов (историй)
- Автоматическое прочтение входящих статусов с отметками о прочтении.
- Автоматические реакции: настраиваемая текстовая последовательность, индивидуальный текст для каждого контакта или случайный набор эмодзи.
- **Поддержка групповых статусов** — статусы, опубликованные в группах WhatsApp, обнаруживаются и обрабатываются тем же конвейером автопрочтения и автореакций, при этом обычные групповые чаты остаются нетронутыми.
- Сохранение статусов — входящие медиа статусов архивируются локально.
- Автоматический ответ на статус с настраиваемым сообщением.
- Ежедневная сводка статусов, отправляемая в Telegram в 23:59 (WIB).

### Приватность и защитные механизмы
- Anti-delete — удалённые сообщения и статусы пересылаются в Telegram вместе с отправителем, номером, временем и содержимым.
- Anti view-once — фотографии и видео с однократным просмотром пересылаются в Telegram, чтобы их можно было открыть снова.
- Режим anti-group — бот полностью молчит в групповых чатах (команды и автоматические функции там не отвечают).
- Строгая политика префикса — команды работают только с префиксом `.`; обычные слова воспринимаются как обычные сообщения.

### Загрузчики медиа
- **TikTok HD 1080p** — загрузка в настоящем качестве 1080p через `.tiktokhd`, а также автоматически при отправке ссылки TikTok в чат без какой-либо команды.
- Слайд-шоу TikTok отправляются одним альбомом.
- Загрузчик аудио/видео YouTube с интерактивным выбором (ответ `1` — MP3, `2` — MP4).
- Создание стикеров, поиск изображений Pinterest и Pixiv и многое другое.

### Мульти-клоны (Jadibot)
- Дополнительные номера WhatsApp можно подключить как клоны с помощью кода сопряжения (`.jadibot <номер>`).
- Все клоны работают в отдельном процессе раннера на той же кодовой базе и наборе плагинов; обновление кода применяется к каждому клону после перезапуска раннера.
- Устаревшие блокировки сессий обнаруживаются и восстанавливаются автоматически.

### Функции ассистента
- Режим AI-чата только для владельца с быстрыми ответами без задержки (`.adawong`).
- Запланированная публикация статусов из очереди ссылок TikTok.
- Анимированная панель загрузки и упорядоченная панель управления статусами (`.sw`).

## Технологический стек

| Компонент | Технология |
| --- | --- |
| Среда выполнения | Node.js (ES Modules) |
| WhatsApp API | Baileys |
| Архитектура | Плагинная система с автоматической загрузкой |
| Хранилище | Файловая база данных JSON (атомарная запись, защита от повреждения) |
| Процесс | Скрипт-супервизор с автоматическим перезапуском и сторожевым таймером соединения |
| Интеграции | Telegram Bot API (пересылка и ежедневная сводка) |

```
│   └── db/                 # Слой базы данных JSON

```

## Установка

```bash
git clone https://github.com/iyannsysu/bot-auto-read.git
cd bot-auto-read
npm install
cp .env.example .env   # заполните свою конфигурацию
bash run.sh
```

При первом запуске бот выводит код сопряжения. Откройте WhatsApp на телефоне,
перейдите в **Связанные устройства** и введите код для подключения.

## Конфигурация

Основные настройки задаются через `.env`:

| Переменная | Описание |
| --- | --- |
| `BOT_NUMBER_OWNER` | Номера владельца, через запятую |
| `BOT_PREFIX` | Префикс команд (по умолчанию `.`) |
| `BOT_ALLOWED_NO_PREFIX` | Разрешить команды без префикса (по умолчанию `false`) |
| `TELEGRAM_TOKEN` | Токен бота Telegram для пересылки (необязательно) |
| `TELEGRAM_CHAT_ID` | Целевой чат Telegram для пересылки (необязательно) |

Переключатели функций статусов во время выполнения (авто-прочтение, автореакции,
автоответ, режим случайных эмодзи, текст реакций) управляются прямо из чата через
панель `.sw` и хранятся в `swconfig.json` — изменения применяются без перезапуска.

## Примеры использования

| Команда | Описание |
| --- | --- |
| `.menu` | Показать меню команд |
| `.sw` | Панель управления статусами (авто-прочтение, автореакции, автоответ) |
| `.tiktokhd <ссылка>` | Скачать видео TikTok в HD 1080p |
| `.tt <ссылка>` | Скачать видео или слайд-шоу TikTok |
| `.play <название>` | Поиск на YouTube, затем ответ `1` (MP3) или `2` (MP4) |
| `.jadibot <номер>` | Подключить новый номер-клон |
| `.status` | Показать состояние основного бота и клонов |
| `.adawong on` | Включить режим AI-чата в текущем чате |

Отправка ссылки TikTok без команды также работает: бот обнаруживает ссылку
и автоматически отвечает HD-видео.

## Примечания

- Это self-bot для личного использования на вашем собственном аккаунте. WhatsApp
  официально не поддерживает неофициальную автоматизацию; используйте ответственно и на свой риск.
- Сессии, `.env`, загрузки и журналы намеренно не включены в этот репозиторий.
