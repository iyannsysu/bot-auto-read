## 概要

**readsw** は、Node.js と Baileys ライブラリで構築された個人用 WhatsApp セルフボットです。
単一オーナー向けアシスタントとして動作し、WhatsApp ステータス（ストーリー）の完全自動化、
高品質なメディアダウンロード、そして同一コードベースから複数の追加番号を運用できる
マルチクローンランナーの 3 つを中核機能としています。

モジュール式のプラグインシステムを採用しており、各機能は起動時に自動で読み込まれる
独立したプラグインファイルです。現在のビルドには **69 個のプラグインと 156 個のコマンド** が含まれます。

## 主な機能

### ステータス（ストーリー）自動化
- 受信したステータスを既読レシート付きで自動既読化。
- 設定可能なテキストシーケンス、連絡先ごとのカスタムテキスト、またはランダム絵文字プールによる自動リアクション。
- **グループステータス対応** — WhatsApp グループに投稿されたステータスを検出し、通常のグループチャットには一切干渉せず、同じ自動既読・自動リアクション処理を行います。
- ステータスセーバー — 受信したステータスメディアをローカルに保存。
- 設定可能なメッセージによるステータス自動返信。
- 毎日のステータス概要を 23:59（WIB）に Telegram へ送信。

### プライバシーとセーフティネット
- 削除対策 — 削除されたメッセージとステータスを、送信者、番号、時刻、内容とともに Telegram へ転送。
- 一度だけ表示対策 — 一度だけ表示の写真と動画を Telegram へ転送し、再表示可能にします。
- グループ無効モード — ボットはグループチャットで完全に沈黙します（コマンドも自動機能も応答しません）。
- 厳格なプレフィックスポリシー — コマンドは `.` プレフィックス付きでのみ動作し、通常の単語は通常メッセージとして扱われます。

### メディアダウンローダー
- **TikTok HD 1080p** — `.tiktokhd` による真の 1080p ダウンロード、およびコマンドなしで TikTok リンクを送信した場合の自動ダウンロード。
- TikTok スライドショー投稿は 1 つのアルバムとして送信。
- 対話式選択が可能な YouTube 音声/動画ダウンローダー（`1` で MP3、`2` で MP4）。
- ステッカーメーカー、Pinterest と Pixiv の画像検索など。

### マルチクローン（Jadibot）
- ペアリングコードで追加の WhatsApp 番号をクローンとして登録可能（`.jadibot <番号>`）。
- すべてのクローンは同一コードベースとプラグインセットで別プロセスのランナーから動作し、コード更新はランナー再起動後に全クローンへ適用されます。
- 陳腐化したセッションロックを自動検出して復旧。

### アシスタント機能
- 遅延のない高速応答が可能なオーナー専用 AI チャットモード（`.adawong`）。
- TikTok リンクキューからのステータス投稿スケジューリング。
- アニメーション付きローディングパネルと整理されたステータス制御パネル（`.sw`）。

## 技術スタック

| コンポーネント | 技術 |
| --- | --- |
| ランタイム | Node.js（ES Modules） |
| WhatsApp API | Baileys |
| アーキテクチャ | 自動ローダー付きプラグインシステム |
| ストレージ | JSON ファイルデータベース（アトミック書き込み、破損対策済み） |
| プロセス | 自動再起動と接続ウォッチドッグ付きスーパーバイザースクリプト |
| 連携 | Telegram Bot API（転送と日次概要） |

## プロジェクト構成

```
readsw/
├── run.sh                  # スーパーバイザー（自動再起動）
├── clone-run.sh            # クローンランナーのスーパーバイザー
├── src/
│   ├── index.js            # メインボットのブートストラップ
│   ├── clone-runner.js     # マルチクローンランナー
│   ├── handler/            # メッセージおよびイベントハンドラー
│   ├── helper/             # 共有ヘルパー（ステータス、ダウンローダー、セッション、ローディング）
│   ├── plugins/            # 機能プラグイン（自動読み込み）
│   └── db/                 # JSON データベース層
└── assets/                 # メニューバナーとロゴ
```

## インストール

```bash
git clone https://github.com/iyannsysu/bot-auto-read.git
cd bot-auto-read
npm install
cp .env.example .env   # 設定を入力
bash run.sh
```

初回起動時にペアリングコードが表示されます。スマートフォンで WhatsApp を開き、
**リンク済みデバイス** からコードを入力して接続してください。

## 設定

主な設定は `.env` で指定します。

| 変数 | 説明 |
| --- | --- |
| `BOT_NUMBER_OWNER` | オーナー番号（カンマ区切り） |
| `BOT_PREFIX` | コマンドプレフィックス（デフォルト `.`） |
| `BOT_ALLOWED_NO_PREFIX` | プレフィックスなしコマンドの許可（デフォルト `false`） |
| `TELEGRAM_TOKEN` | 転送用 Telegram ボットトークン（任意） |
| `TELEGRAM_CHAT_ID` | 転送先 Telegram チャット（任意） |

ステータス機能（自動既読、自動リアクション、自動返信、ランダム絵文字モード、リアクションテキスト）の
実行時トグルは、`.sw` パネルからチャット内で管理でき、`swconfig.json` に保存されます。
変更は再起動なしで反映されます。

## 使用例

| コマンド | 説明 |
| --- | --- |
| `.menu` | コマンドメニューを表示 |
| `.sw` | ステータス制御パネル（自動既読、自動リアクション、自動返信） |
| `.tiktokhd <リンク>` | TikTok 動画を HD 1080p でダウンロード |
| `.tt <リンク>` | TikTok 動画またはスライドショーをダウンロード |
| `.play <タイトル>` | YouTube を検索し、`1`（MP3）または `2`（MP4）で返信 |
| `.jadibot <番号>` | 新しいクローン番号をペアリング |
| `.status` | メインボットとクローンの状態を表示 |
| `.adawong on` | 現在のチャットで AI チャットモードを有効化 |

TikTok リンクをコマンドなしで送信することもできます。ボットがリンクを検出し、
HD 動画で自動的に返信します。
